💡 How to Use These Tools

Finding Player IDs

Player IDs are typically lowercase with underscores. Examples:

  • Patrick Mahomes → mahomes_patrick
  • Josh Allen → allen_josh
  • Travis Kelce → kelce_travis

Understanding Edge

Edge represents your expected advantage:

  • Positive edge: Model thinks bet has value
  • >5% edge: Strong betting opportunity
  • >10% edge: Excellent value

Kelly Criterion

Suggested bet size as % of bankroll:

  • Based on edge and confidence
  • Conservative: Use 0.25-0.5x Kelly
  • Never bet more than Kelly suggests
